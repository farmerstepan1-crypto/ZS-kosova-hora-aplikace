ZEMĚDĚLSKÁ SPOLEČNOST KOSOVA HORA a.s. – základ aplikace

NAHRÁNÍ DO GITHUBU (mobil):
1. Rozbal ZIP.
2. Otevři repozitář ZS-kosova-hora-aplikace na GitHubu.
3. Nahraj obsah této složky do hlavní úrovně repozitáře (ne pouze nadřazenou složku).
4. Potvrď změny (Commit changes).
5. Pokud je zapnutý GitHub Pages, aplikace se zobrazí jako webová stránka.

FUNKCE:
- mapa OpenStreetMap se zaměřením na oblast Kosovy Hory,
- přidávání, úprava a mazání pozemků,
- umístění pozemku klepnutím do mapy,
- přehled a součet výměr,
- export a import zálohy JSON,
- uložení záznamů v prohlížeči daného zařízení.

DŮLEŽITÉ:
Toto je základní funkční verze. Skutečné hranice a čísla LPIS nejsou zatím automaticky připojené.
Záznamy se ukládají do místního úložiště prohlížeče; pro sdílení mezi více lidmi bude potřeba
doplnit společnou databázi a přihlášení. Mapa potřebuje internetové připojení.
Logo v assets/logo.jpg je převzaté z dodaného obrázku bez změny jeho barev a nápisu.
